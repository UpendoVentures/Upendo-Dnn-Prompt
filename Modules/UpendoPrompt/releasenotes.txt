		<h3>Version 01.11.00</h3>
		<h4>Enhancements</h4>
		<ul>
			<li>Added <code>set-largefileupload</code> as a new command. This safely toggles the upload limits needed to install larger extension packages by applying the matching XML merge file, then allows administrators to run the same command again to restore the default upload limits. This helps avoid manual <code>web.config</code> edits and reduces the chance of leaving larger upload limits enabled longer than needed. (<a href="https://github.com/UpendoVentures/Upendo-Dnn-Prompt/issues/84" target="_blank">Issue 84</a>, thanks <a href="https://github.com/WillStrohl" target="_blank">@WillStrohl</a>!)</li>
			<li>Added <code>set-localsmtpfolder</code> as a new command. This safely toggles local SMTP pickup delivery by creating an <code>_SMTP</code> folder in the website root and applying the matching XML merge file to update <code>web.config</code>. Running the command again removes the local SMTP configuration while leaving the <code>_SMTP</code> folder in place, making it easier to test email delivery without manually editing configuration files. (<a href="https://github.com/UpendoVentures/Upendo-Dnn-Prompt/issues/88" target="_blank">Issue 88</a>, thanks <a href="https://github.com/WillStrohl" target="_blank">@WillStrohl</a>!)</li>
			<li>Added <code>set-rememberlogin</code> as a new command. This safely toggles the recommended persistent login settings for the Remember Login option by applying the matching XML merge files. Running the command once extends the login timeout and persistent cookie timeout, then running it again restores the default values. This helps administrators improve login convenience without manually editing <code>web.config</code>. (<a href="https://github.com/UpendoVentures/Upendo-Dnn-Prompt/issues/89" target="_blank">Issue 89</a>, thanks <a href="https://github.com/WillStrohl" target="_blank">@WillStrohl</a>!)</li>
			<li>Raised the minimum supported DNN version to 09.13.00. This aligns installation, development, testing, and support with a newer baseline and reduces maintenance overhead from older platform behavior. (<a href="https://github.com/UpendoVentures/Upendo-Dnn-Prompt/issues/82" target="_blank">Issue 82</a>, thanks <a href="https://github.com/WillStrohl" target="_blank">@WillStrohl</a>!)</li>
